# Autonomous Research Agent (LangChain)

## Objective
This project builds an AI agent that can automatically research a topic and generate a structured report.

## Features
- Web Search using LangChain tools
- Wikipedia Knowledge Tool
- Autonomous Agent (ReAct)
- Generates structured reports

## Tech Stack
- Python
- LangChain
- Groq / LLM

## Sample Outputs
Two reports generated:
- Impact of AI in Healthcare
- Impact of AI in Education

## How to Run
1. Install dependencies
2. Add API key
3. Run notebook
4. Enter topic

## Output Format
- Cover Page
- Title
- Introduction
- Key Findings
- Challenges
- Future Scope
- Conclusion
